# Contact Book 📒

A simple contact book application written in Python. This project allows users to manage their contacts through a command-line interface.

## Features

- Add new contacts
- View all saved contacts
- Edit existing contact information
- Delete contacts
- Prevent duplicate contact names

## Technologies Used

- Python 3
- Git
- GitHub


## Getting Started

### Prerequisites

- Python 3 installed on your computer
- Git installed on your computer

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Mehrnoosh-Salehi/contact-book.git
   ```

2. Navigate to the project directory:

   ```bash
   cd contact-book
   ```

3. Run the application:

   ```bash
   python3 src/main.py
   ```

## Usage

When you run the application, a menu appears with the following options:

1. Add contact
2. Edit contact
3. View contact
4. Delete contact
5. Quit

Choose an option and follow the instructions displayed in the terminal.
